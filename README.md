# PopX - React JS Interview Assignment

A pixel-perfect implementation of the **PopX** user authentication flow web application, engineered using **React JS** and **Vite**. This project satisfies the requirements for the Intern/Fresher React JS Qualifier task.

## Repository Links
* **GitHub Repository:** https://github.com/PurviMalani03/popx-app

---

##  Features & App Flow

The application renders as a centralized mobile interface layout floating on desktop screen form-factors, matching the Adobe XD project guidelines perfectly:

1. **Landing Screen (`/`):** Clean onboarding screen directing users to either create an account or sign in.
2. **Login Screen (`/login`):** Validated inputs for existing users to authenticate.
3. **Signup Screen (`/signup`):** Full profile creation form (Name, Phone, Email, Password, Company, Agency toggle) handling responsive component states.
4. **Profile Screen (`/profile`):** Dynamic user profile dashboard rendering account status and input details seamlessly.

---

##  Tech Stack & Architecture

* **Framework:** React 18 (via Vite for blazing-fast build performance)
* **Routing:** React Router DOM v6 (ensures clean navigation and bookmarkable layout URLs)
* **Styling:** CSS3 Custom Variables / BEM-inspired structuring for semantic architecture.
* **State Management:** Integrated React Context / Global State Hooks to pass signup form inputs into the profile view dynamically.
